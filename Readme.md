# CryptoLens

CryptoLens is a Streamlit crypto analytics dashboard that pulls live market data from the CoinGecko API and analyzes price, momentum, volatility, drawdown, RSI, and trading volume.

## Features

- Select Bitcoin, Ethereum, or Solana
- Choose the number of days of historical data
- View current price, RSI, drawdown, and market label
- Generate simple market signals
- Interactive Plotly charts
- Raw data table for inspection

## Metrics Included

- Price
- Returns
- 24H moving average
- 7D moving average
- Rolling volatility
- Drawdown
- RSI
- Volume

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- CoinGecko API
